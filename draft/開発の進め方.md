# 開発の進め方（アイデア確定前の準備）

## モデル分担
| 役割 | モデル | 範囲 |
|---|---|---|
| designer (`.claude/agents/designer.md`) | Opus | 企画の具体化、デザイン、描画、開発プラン |
| worker (`.claude/agents/worker.md`) | Sonnet | 実装、データ入力、テスト、整理、コミット |

メインの会話は依頼ごとに上記へ振り分ける（Agentツールで `designer` / `worker` を指定）。

## 流れ
1. `reference/アイデア.txt` にアイデアを書く（現在は空）
2. 不明点をユーザーに質問（CLAUDE.md §5）
3. designer: `draft/企画書.md`（コンセプト、ルール、画面、演出）と `draft/開発プラン.md`（技術選定、タスク分解）を作成
4. ユーザー承認
5. worker: タスクを順に実装 → designer が見た目をレビュー
6. 区切りごとにコミット。公開は別途確認
