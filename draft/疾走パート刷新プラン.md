# 疾走パート刷新プラン（2026-10-30）

リズムゲーム（ノーツ判定で加速）をやめ、**「自転車で走りながら刀で障害物を斬り、背後の闇から逃げ切る」**横スクロールに作り替える。
あわせて、合成音の曲と効果音を**フリー音源の生録音**に差し替える。
帰り道 → 襲来 → 回顧 → 渦 → 疾走 → 白光 → 結末 の流れと、絵（art_r1〜r3）はそのまま使う。

## 1. 決まったこと（ヒアリング結果）
| 項目 | 決定 |
|---|---|
| 遊びの核 | 障害物よけ（ランナー）＋追跡から逃げ切る |
| 操作 | タップ/クリック/キー **1つ** ＝ 刀で一閃（自転車なのでジャンプはしない） |
| 障害物 | 世界ごとの物体（文字は使わない） |
| 追跡者 | 黒系のピクセルでできた**闇のさざ波**（画面左から迫る） |
| 斬り損ね | 衝突でよろけて減速 → 闇が迫る。空振りは短い硬直（連打対策） |
| 斬りの手応え | ①ジャスト斬りで大加速 ②連続斬りでコンボ ③破片が飛び散る＋ヒットストップ |
| 呑まれる条件 | さざ波の幅で見せる（線は描かない）。一定の幅を越えると呑まれる |
| ゲームオーバー | 呑まれる → 闇が急加速して画面全体を覆う → ネガティブな一言が大きく出る → 闇がサーっと引く → **誰も乗っていない自転車だけが惰性で走っている** → 専用の結末 → タイトル |
| 長さ | 1ラウンド約40秒 × 3ラウンド |
| 音楽 | BGMのみ（判定は音と無関係）。**疾走は曲の山場を切り出して構成**し、終盤の最高潮で白光 |
| 音源 | Musopen / Wikimedia Commons / Internet Archive のPD・CC0（またはCC BY）録音 |
| 効果音 | 効果音もフリー音源の録音 |

> 以前の決定「敗北なし」は今回の回答で**上書き**（呑まれたらゲームオーバー）。逃げ切ったラウンドの成績で結末ランク S/A/B/C は残す。

## 2. ゲームの仕様（初期値。遊んで調整する前提）

### 2-1. 画面（320×180 のドット絵キャンバスのまま）
```
 ← 闇のさざ波        自転車+刀       障害物が右から流れてくる →
 ▓▓▓▒▒░            🚲⚔  [間合い]          ■        ▲
 ▓▓▓▒▒░  ────────────────────────────────────────── 地面
 |<-- この幅が画面の1/3を越えたら呑まれる
```
- 自転車は x≈110 付近に固定。背景と障害物が右から左へ流れる（流れる速さ＝速度）。
- 刀の**間合い**は自転車の前方 約24px。JUST 判定は、間合いの先端付近の 約6px。
- 闇は左端から伸びる。幅は 0〜1（画面幅に対する割合）で、**0.33 を越えたら呑まれる**。近づくほど濃くなり、ざわめく音が大きくなる。

### 2-2. 操作と判定
| 起きたこと | 判定 | 速度 | 闇の幅 | その他 |
|---|---|---|---|---|
| 間合いの先端で斬る | JUST | +6 | −0.06 | ヒットストップ 60ms・破片多め・コンボ+1 |
| 間合いの中で斬る | GOOD | +3 | −0.02 | ヒットストップ 30ms・コンボ+1 |
| 何もない所で斬る | 空振り | 0 | 0 | 0.25秒の硬直（その間は斬れない） |
| 障害物にぶつかる | 衝突 | −12 | +0.08 | よろけ演出・コンボ0 |
| 時間経過 | — | 少しずつ低下 | 速度が低いほど少しずつ増える | 何もしないと闇に追いつかれる |
- コンボ 5 ごとに速度上昇の量が増える（×1.2, ×1.4 …上限あり）。コンボが続くほど残像・色相回転が強くなる（現在の演出を流用）。
- 速度は 0〜100（現在のメーターを流用）。遅くても止まらないが、闇が伸びやすくなる。

### 2-3. 障害物（世界ごと）
| ラウンド | 世界 | 障害物の例（designer が確定） |
|---|---|---|
| R1 | アルルの夜道（ゴッホ） | 糸杉の枝、カフェの椅子、絵の具の缶、石 |
| R2 | 夜の合戦場 | 竹の柵、倒れた旗指物、矢の束、樽 |
| R3 | 夜の高校の廊下 | 机、掃除用具入れ、開いたロッカーの扉、紙飛行機の束 |
- 出現の間隔は、ラウンドが進むほど・速度が上がるほど詰まる。2つ続けて来る形も混ぜる（連続斬りのため）。

### 2-4. ラウンドの終わり方
- **逃げ切り**: 曲の切り出し（約40秒）の最高潮で白光 → 現実へ戻る（今の白光シーンを流用）。
- **呑まれる**: 2-5 の演出 → 専用の結末 → タイトル。
- 成績（ラウンドごと）: 斬った率、JUST率、衝突数、最大コンボ、闇との最接近。

### 2-5. ゲームオーバー演出（ユーザー指定どおり）
1. 闇の幅がしきい値を越えた瞬間、闇が**急加速**して画面全体を覆う（0.6秒）。
2. 真っ黒な画面に**ネガティブな一言**が大きく出る（回顧文の一言から選ぶ。例:「あの一言、余計だったろ」）。BGMは止まる。
3. 次の瞬間、闇が**サーっと**左へ引く（0.8秒）。
4. **誰も乗っていない自転車だけが**惰性で走り、ゆっくり止まる（3〜4秒）。
5. 専用の結末テキスト → タップでタイトルへ。

### 2-6. 結末ランク（3ラウンド逃げ切った場合）
- 点数 = 斬った率×50 + JUST率×30 + 闇との平均距離×20（初期値。調整する）
- S/A/B/C の分岐と玄関の絵は今のまま使う。

## 3. 音（フリー音源）

### 3-1. 曲の割り当て（候補。最終的にはユーザーが耳で選ぶ）
| 場面 | 曲 | 使い方 |
|---|---|---|
| タイトル・結末 | パーセル『メアリー女王の葬送音楽』 | そのまま |
| R1 疾走 | ロッシーニ『ウィリアム・テル』序曲 終結部（スイス軍の行進） | 山場 約40秒を切り出し |
| R2 疾走 | エルガー『威風堂々』第1番 | 山場 約40秒を切り出し |
| R3 疾走 | ベートーヴェン 交響曲第9番（第2楽章 または 第4楽章） | 山場 約40秒を切り出し |
| 回顧 | その回の疾走曲の静かな部分 | ローパスでこもらせる（今の処理を流用） |
| ゲームオーバー | 無音 → 惰性の場面だけ小さく環境音 | — |
| 予備 | ベートーヴェン 交響曲第5番 冒頭、ロッシーニ『泥棒かささぎ』序曲 | 結末/タイトルの差し替え候補 |

### 3-2. 効果音
斬撃（刀の風切り）、斬った手応え（木や布が裂ける音）、衝突、闇のざわめき（ループ）、自転車のチェーン音・惰性の回転音、白光。
入手先: Freesound（CC0に限定）、OpenGameArt（CC0）。

### 3-3. ライセンスの扱い（重要）
- 作曲はPDでも、**録音（演奏）には別の権利**がある。録音ごとにライセンスを確認し、PD / CC0 / CC BY だけを使う（CC BY-NC・ND、ライセンス不明は使わない）。
- `output/audio/CREDITS.md` に 曲名・演奏者・入手URL・ライセンス を記録。CC BY のものはタイトル画面の「クレジット」に表示する。
- 形式は **MP3**（iPhone Safari でも鳴る）。切り出し・音量そろえは ffmpeg で行う（PCに入っているか未確認）。
- ダウンロードした原本は `inbox/音源_原本/` に置き、加工後のものだけを `output/audio/` に置く。
- Freesound はダウンロードにログインが必要。手動ダウンロードをお願いする場面がありうる。

## 4. 技術方針（今のコードからの変更点）
| ファイル | 扱い |
|---|---|
| `src/rhythm_engine.js`, `test/rhythm_test.html` | `archive/` へ移す |
| `src/songs_*.js`, `src/songs.js` | `archive/` へ移す（合成曲はやめる） |
| `src/audio_engine.js` | `type:'file'` の再生（実装済み）を使う。拍・判定まわりは外し、**区間再生・クロスフェード・ローパス・効果音（録音）再生**を中心に整理 |

## 6. まだ決めていないこと（作りながら決める）
- 速度の役割：今は「白光は曲の最高潮（時間）で来る」とした。元の企画「スピードが最高潮に達したら白光」に寄せて、**速度100で白光を早められる**ようにするか。
- 呑まれたときの「ネガティブな一言」を回顧文から選ぶか、専用に書くか。
- ゲームオーバーの専用結末の文と絵（無人の自転車のまま終わるか、家の前の場面を挟むか）。
- 闇のしきい値（1/3）が、絵として近すぎ/遠すぎないか。
