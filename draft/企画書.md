# 悪態独り 企画書（v0.1 / designer）

> **注記（2026-10-30）: 疾走パート刷新により一部旧仕様。** E パート（リズム判定・BPM上昇・救済・敗北なし）、§5 の判定と速度の表、合成音の曲は `draft/疾走パート刷新プラン.md` で置き換えた（刀で斬る逃走ランナー・闇に呑まれるとゲームオーバー・録音MP3）。本文は記録として残す。

## 1. コンセプト
人と会った帰りの夜道。思い出すのは自分の失言・すべり・だらしなさばかり。
その「ああああー、アウっ！！」が化け物（ハクチョウ等）になって襲いかかり、世界がねじれて異世界になる。
プレイヤーは悪態のリズムに乗って異世界を疾走し、最高速に達すると白光とともに現実の夜道に戻る。これを3回くり返して家に着く。

- 1人用 / ブラウザ / キーボード・タッチ両対応 / 約5分 / 敗北なし
- タイトル案: 「悪態独り」（変更なし）

## 2. 面白さの核
1. **恥の変換**: 具体的で情けない回顧文（読ませる）→ 突拍子もない化け物と異世界（笑わせる）の落差。
2. **悪態＝ビート**: 頭の中で止まらない悪態を、クラシックのモーグ風ビートに乗せて叩き続ける。叩くほど加速し、曲もテンポが上がる（時計じかけのオレンジの早回し的な高揚）。
3. **白光のカタルシス**: 最高潮で真っ白→無音→ただの夜道。この落差がオチ。
4. 敗北がないので「うまく叩けたか」は結末の一言にだけ効く。

## 3. 1ラウンドの流れ（約1.5〜2分）
| # | パート | 長さ | 画面・演出 | 操作 |
|---|---|---|---|---|
| A | 帰り道（現実） | 15秒 | 横スクロールの夜道を主人公が右へ歩く。街灯、自販機、遠くの信号。頭上に小さな独り言がポツポツ浮かんで消える（「…なんであそこで」）。BGMなし、足音と環境音のみ | なし（自動） |
| B | 襲来 | 4秒 | 画面右上から襲来物が出現→急接近。画面端に赤い走査線、心拍音 | なし |

| D | 突入 | 2秒 | 衝突→画面が渦状にねじれる/割れる→異世界へ | なし |
| E | 異世界疾走 | 45〜75秒 | 異世界を右へ疾走（多層パララックス）。画面下部にビートレーン。速度メーター。曲がテンポアップしていく | リズム入力 |

## 4. 3ラウンドの組（提案。差し替え可）
夜であることは全ラウンド不変。

| R | 襲来物 | 異世界 | 回顧のテーマ | 曲（PD） | BPM 開始→最高 |
|---|---|---|---|---|---|
| 1 | **ハクチョウ**（右上から首を伸ばして滑空） | **アルルの夜道**（渦巻く星空、糸杉、黄色い街灯のカフェ。筆致の点描） | すべったエピソードトーク、話の順序 | ロッシーニ『ウィリアム・テル』序曲「スイス軍の行進」 | 120→150 |
| 2 | **騎馬武者**（色のない灰色の騎馬が闇から突進） | **夜の合戦場の野原**（篝火、旗指物、満月、すすき） | 権威ある人との食事で色も味も消えた、人の話をさえぎった/奪った | エルガー『威風堂々』第1番 | 112→144 |
| 3 | **紙飛行機の大群**（誰にも覚えられていない一言が書かれている） | **永遠に続く夜の高校の廊下**（非常灯の緑、窓の月、無限に続く教室札） | 二千円のマンゴージュース、誰も覚えていない一言、だらしない恰好 | ベートーヴェン 交響曲第9番「歓喜の歌」（行進曲風） | 120→168 |

- 理由: R1はアイデア文の起点。R2は「行進＝権威」で威風堂々が合う。R3は歓喜の歌を最後に置き、最もテンポを上げてクライマックスにする（廊下の一点透視は速度感が最も出る）。
- タイトルと結末: パーセル『メアリー女王の葬送音楽』を遅いモーグで（時計じかけのオレンジのメインテーマ的位置。没1695でPD）。
- 注意: 作曲はPDだが、ウェンディ・カーロス等の既存編曲・録音は著作権あり。**旋律は楽譜から自作編曲**し、既存録音の音や編曲を写さない。

## 5. リズム判定とスピード上昇の仕様（E パート）
### 入力
- キーボード: どのキーでも1打（Space/Enter/矢印/文字キー）。キーリピートは無視（`e.repeat`）。
- タッチ/マウス: 画面どこでも `pointerdown` で1打。
- 判定時刻は `AudioContext.currentTime`（音と同じ時計）で取る。`performance.now()` は使わない。

### ノーツ
- 基本は4分音符ごとに1打（ビートに合わせる）。ノーツは画面下部のレーンを右→左に流れ、判定線で叩く。
- 速度60%以上で8分音符が混ざる（小節の後半2拍が8分）→「連打」感。
- 速度90%以上「疾走ラスト」: 2小節すべて8分（連打区間）。

### 判定窓（初期値、調整可）
| 判定 | ずれ | 速度変化 |
|---|---|---|
| PERFECT | ±50ms | +4 |
| GOOD | ±110ms | +2 |
| MISS（ノーツを叩かず通過 / 空打ち） | それ以外 | −3（空打ちは−1） |
- 速度 `speed` は 0〜100。入力がない間は毎秒−1で自然減衰。
- 連続PERFECT/GOODでコンボ。10コンボごとに+5ボーナス。

### テンポ上昇
- `bpm = bpmStart + (bpmMax - bpmStart) * (speed/100)` を **小節の頭でだけ** 更新（途中で変えるとノーツがずれるため）。
- 背景スクロール速度・足の回転・風の線の量も `speed` に比例。
- 救済: Eパート開始から60秒経っても100に届かなければ、以降の速度を自動で上げて75秒までに必ず100に到達させる（敗北なし）。到達した事実は成績に記録。

### 成績の記録（ラウンドごと）
- `accuracy` = (PERFECT×1 + GOOD×0.5) / 全ノーツ数
- `reachTime` = 100到達までの秒数（救済で到達した場合は `assisted=true`）
- `maxCombo`

## 6. 成績 → 結末の分岐
- スコア = 3ラウンド平均 accuracy ×70 + 自力到達ラウンド数×10（最大100）
- 4段階で結末を変える（文言は `draft/回顧文_下書き.md` 末尾の下書きを使う）

| ランク | 条件 | 結末の演出 |
|---|---|---|
| S | 85以上 | 玄関前で立ち止まる。最後の独り言が少し前向き。家の窓に明かり |
| A | 65〜84 | 普通に帰宅。苦笑いの一言 |
| B | 40〜64 | 鍵がなかなか見つからない。悪態が一つ残る |
| C | 40未満 | 家の前を通り過ぎてもう一周しそうになる。自嘲 |
- 結末画面: 玄関の絵＋一言（大きめ）＋小さく成績（精度%、最高速度到達時間、最大コンボ）。「もういちど」。

## 7. 見た目・文字スタイル
### 参考（虫アプリ_ver4）から踏襲するもの
- **描画方式**: 低解像度の内部キャンバスに描き、CSSで16:9に拡大（`image-rendering: pixelated`、`imageSmoothingEnabled=false`）。外部画像なし、絵はすべてコードで生成。
- **パレット方式**: 色は1か所の `PALETTE` 配列で定義し、絵はパレット番号の2次元配列（0=透明）で描く。共通の輪郭色を1色決める。
- **文字表示**: 文字はキャンバスに描かず、画面解像度のHTMLオーバーレイ（`#ui`）で重ねる。フォントは `DotGothic16`（Google Fonts）＋日本語フォールバック。4方向の `text-shadow` で縁取り。キャプションは opacity のフェードで出し入れ。
- **巨大文字**: ver4 の「巨大な白文字＋`-webkit-text-stroke`＋`paint-order:stroke fill`」を叫び（アウっ！！）と判定表示に流用。
- 16:9固定・中央配置、`dvh` 対応、縦持ち時は横向きを勧める表示。

### がらっと変えるもの
| 項目 | ver4（参考） | 悪態独り |
|---|---|---|
| 内部解像度 | 256×144 | **320×180**（疾走のパララックス層を増やすため） |
| 色調 | 暖色（チーク材の茶、クリーム、金） | **夜の寒色＋毒々しい差し色**。ベース: 濃紺 `#0a0b1e` / 群青 `#1b2350` / 紫紺 `#2c1f4a`。光: 街灯ナトリウム橙 `#ffb347`、月白 `#e8f0ff`。悪態の差し色: マゼンタ `#ff2e88`。異世界ごとに差し色1色を追加（R1 ゴッホ黄 `#f5d33a`、R2 篝火朱 `#ff5a1f`、R3 非常灯緑 `#3dff8a`） |
| 輪郭色 | 焦げ茶 `#2a1810` | **ほぼ黒の藍** `#05060f` |
| 文字色・縁 | クリーム `#fff4e0`＋焦げ茶縁 | **月白 `#e8f0ff`＋藍黒縁**。回顧文はやや大きく、行頭に「─」。叫びはマゼンタ縁の白 |
| 雰囲気 | 机の上を俯瞰、静かで温かい | **横スクロール**、冷たい夜→異世界でサイケ（色相回転、走査線、残像） |
| 文字演出 | フェードのみ | フェード＋回顧文の1文字ずつ表示＋叫びの震え（CSS animation） |

### 演出の要点
- スロー: `timeScale=0.05`、キャンバスに青黒の半透明を重ね、音は lowpass 400Hz に落とす。
- 疾走中: speed 70%以上で画面端に色収差風の残像（前フレームを半透明で重ねる）、90%以上で色相回転（CSS `filter: hue-rotate` を canvas に）。
- 白光: 0.3秒で白に → 1秒保持（無音）→ 1.5秒で夜道へフェード。

## 8. 最低限必須 / 余裕があれば
### 最低限必須（MVP）
- タイトル → 3ラウンド（A〜F全パート）→ 結末、を通しで遊べる
- リズム判定・速度・テンポ上昇・白光
- 回顧文（各ラウンド候補からランダム1本）
- WebAudioの自作モーグ風曲 ×3（各ラウンド）
- 成績4段階の結末
- キーボード/タッチ両対応、file:// で起動可

### 余裕があれば
- タイトル/結末のパーセル曲
- 音ずれ補正（キャリブレーション画面）
- 異世界ごとの固有演出（R1 星が渦を巻く、R2 矢の雨をすり抜ける、R3 教室の扉が開閉）
- 帰り道の独り言のランダム生成（ver4の組み合わせ生成の知見を流用）
- 音源ファイルへの差し替え（音源を用意したら）
- 録画、英語版、PWA
