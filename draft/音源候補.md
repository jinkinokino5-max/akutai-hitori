# 音源候補（2026-10-30 調査 / 手順1）

- 調べ方: Wikimedia Commons の API で「ライセンス・演奏者・長さ・出典」を取得。**まだ1曲もダウンロードしておらず、聴いてもいない**（旋律・音質・山場の位置は未確認）。
- 作曲がPDでも**録音には別の権利**がある。下の「権利の根拠」が強い順に並べた。
- ダウンロードはユーザーが曲を選んでから行う。原本は `inbox/音源_原本/`、加工後は `output/audio/` に置き、`output/audio/CREDITS.md` に出典とライセンスを記録する。

## 権利の強さの見方
| 記号 | 意味 |
|---|---|
| ◎ | 米国政府（海兵隊・陸軍バンド）の録音。米国では政府職員の著作物は著作権なし。Commons も Public domain 表示 |
| ○ | 1923年より前の録音など。Commons が Public domain 表示（根拠は各ページ） |
| △ | Commons が PD 表示だが、1950年代の商業盤の可能性があり、**根拠が弱い**。使う前に原典を再確認する |
| CC BY | 使えるが、タイトル画面などに**クレジット表示が必須** |
| CC BY-SA | クレジット表示＋改変物の同条件公開が必要。避けたい |

## 決めてほしいこと
1. 各ラウンドの曲を選ぶ（上の表から。迷ったら **1-A / 2-A / 3-A**）。→ 先に3〜5曲だけダウンロードして、ブラウザで聴き比べる。
2. 権利を重視するか、曲の雰囲気を重視するか。第九は 3-A が△、3-D が◎で第九ではない。
3. CC BY（クレジット表示）を許容するか。許容すれば P-A が使える。

## 技術メモ
- **ffmpeg が入っていない**。切り出し・MP3化は次のどちらか。
  - ① `winget install Gyan.FFmpeg` で導入（ユーザーの許可が必要）。
  - ② 再生側で区間（start/end）を指定して原本の ogg をそのまま使う。ファイルが大きい（11分の曲で12MB）ので、公開サイズが重くなる。
- 形式は iPhone Safari で鳴る MP3/AAC を基本にする。Commons の ogg/opus/flac は iOS で鳴らない場合があるため、変換が必要。
