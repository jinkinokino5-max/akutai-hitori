# 並列開発の共通ルール（全サブエージェント必読）

- T1(土台)は別担当が `output/index.html` と `output/src/{core,input,audio,songs,rhythm,art,scenes,ui,main}.js`, `output/data/*.js` を作成・編集中。**これらの既存ファイルは編集しない**。自分の担当は下記の「新規ファイル」だけを作る。
- 統合(index.html への script 追加、既存足場との接続)は後で別担当が行う。そのため各ファイルは `window.AT = window.AT || {};` で始め、クラシック `<script>` で読める形(ES modules・import/export 禁止、ビルド不要)にする。
- 画面は 320×180 の Canvas2D、ドット絵。夜の寒色+マゼンタが基調(企画書§7)。主人公は自転車で帰る人。
- 自分の API は `draft/api_<担当名>.md` に簡潔に書く(統合担当が読む)。
- ファイル削除禁止、push 禁止、コミットは自分の新規ファイルだけを `git add <パス>` して行う(他担当の変更を巻き込む `git add -A` 禁止)。コミット末尾: `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`
- 検証: `node --check` で構文確認し、可能なら node で単体テスト(音楽ならパース検証、絵ならスプライト配列の寸法検証)。ブラウザで確認できなければ「未確認」と明記。
- 事実不明(楽譜の正確性など)は断定せず「未照合」とコメントに書く。既存の電子編曲・録音の採譜はしない。パブリックドメインの原曲旋律を自分で書き起こす。
- 報告は日本語・簡潔(各10行以内)。
